# Light production and racial buildings

Added Factory (250 gold / 300 wood, 40 seconds), Sanctuary (300 / 200, 35 seconds), and Shipyard (150 / 300, 35 seconds) as Production buildings requiring Castle level 2.

Added Dwarven Forge (250 / 150, 50 seconds) as a Racial building requiring Barracks level 1 and Castle level 1, and Human Monument (300 / 200, 50 seconds) as a Racial building requiring Castle level 2.

All five use existing Light icons, worker construction, structured minimum-level requirements, automatic dependency insertion, and existing per-copy pricing. Updated the README and catalog documentation. No unconfirmed units or limits were added.
