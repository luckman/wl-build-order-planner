# Light building upgrades

Added level 2 upgrades for Barracks (50 gold / 100 wood, 35 seconds), Factory (100 / 100, 45 seconds), Sanctuary (150 / 100, 40 seconds), and Shipyard (50 / 150, 40 seconds), requiring Castle level 3.

Added Dwarven Forge levels 2 (300 / 200, 65 seconds) and 3 (350 / 250, 80 seconds), Human Monument levels 2 (350 / 250, 65 seconds) and 3 (400 / 300, 80 seconds), and Elven Tree levels 2 (250 / 350, 65 seconds) and 3 (300 / 400, 80 seconds). Level 2 requires Castle level 3; level 3 requires Castle level 4.

Linked every upgrade to its preceding building level with structured requirements, preserving existing icons, types, fixed upgrade prices, worker timing, and recruitment capability. Updated README and catalog documentation.
